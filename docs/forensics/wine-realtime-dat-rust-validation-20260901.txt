Derived OEM rules
-----------------
- Price scale is 100 for 5,335 records and 1,000 for 876 records.
- Amount mode is selected from slot bytes +0x2aa/+0x2ab: mode 0 has 158
  records, mode 1 has 86, and mode 2 has 5,967.
- Mode-0 tagged values follow exporter function 0x40ac30: clear bit 31,
  widen to u64, shift left 16, then round to f32. This is distinct from the
  TDX 7709 packed-number decoder. SH113624 0x8000b09c -> f32 bits 0x4f309c00;
  SZ123118 0x80012077 -> f32 bits 0x4f903b80.
- weiBi = (buy_raw - sell_raw) * 100 / (buy_raw + sell_raw), with zero
  denominator returning zero.
- liangBi = volume * (lot_adjustment + 1) /
  (base_volume * (foot + 1)), with zero denominator returning zero.
- change uses FIN metrics[35] for category 2 or 17, otherwise metrics[34],
  and returns zero when finance is absent or the denominator is zero.
- The object_09/object_04/current-category join covers 5,958 records. Rust
  and Wine change f32 bits match for all 5,958. Another 321 records lack the
  same-capture finance object and 19 lack current classification, so they were
  excluded rather than inferred.
