Main-data outer wrapper
-----------------------
- Objects 01/02/03/04/09/10 use the same 264-byte prefix and four-byte zero
  suffix.
- Comparing all six prefixes shows that only eight u32 length fields vary:
  offsets 32, 36, 44, 56, 98, 102, 242 and 254.
- encode_main_data_outer_object recalculates those fields from the inner object
  length and preserves every inner byte.
- Round-trip fixture result: all six complete objects match byte-for-byte.

File outer wrapper

Simple control-message family
-----------------------------
- Objects 06/07/08/11 share one serialized skeleton. After removing the title
  and body, the fixed parts have lengths 126, 92, 26 and 4 bytes.
- Title and body are UTF-16LE with NUL terminators and are each serialized twice.
- Every other difference is derived from their lengths, except one observed
  message-family marker: notice=0x606f and status-update=0x65b0.
- encode_control_message reconstructs all four distinct messages exactly.
- Captured duplicate checks prove object_13==object_06,
  object_14==object_07 and object_15==object_08.

Compound control packet

  response, module, packet name, response packet, response number, notice and
  initialization complete.
- Only one authoritative object_12 is available. The codec therefore exposes a
  fixed semantic template instead of claiming unsupported parameter rules.
- encode_initialization_control_packet matches all 460 captured bytes.

Inner-object evidence boundary
------------------------------
- The complete wrapper round trips above use captured inner bytes to isolate and
  prove wrapper behavior.
- Independent structured encoders already cover code tables, splits, finance,
  file payload, realtime and empty realtime objects.
- Structured comparisons normalize only explicitly identified Wine
  uninitialized UTF-16 slot tails and the separately documented realtime
  one-byte capture phase. Those unstable bytes are not copied into protocol
  constants.
- This closes the captured object_01..15 formats. It does not by itself prove
  live initialization timing, callback ordering under every failure mode, or
  intraday quote quality.
