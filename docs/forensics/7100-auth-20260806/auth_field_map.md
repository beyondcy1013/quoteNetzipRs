## 5. 随机数、时间戳和 token

- 74 B 网络包头和标准 ZSTD 解压后的测速/登录体中没有找到独立 nonce、Unix 时间戳、cookie 或 token 标签。
- 7100 响应解压长度 328 B，包含 `认证` 和 `登录` 标记，但没有可复用 token 的已确认字段。
- 6100 首个字典响应 439 B 经 `Stock.字典` 解压为 620 B；其中有 `账号` 标签，值未输出，尚未证明它是会话 token。
- TCP 序列号属于传输层，不能当作应用随机数。
- `Tdx_Encrypt` 的 0x118 B 体属于既有 7709 bootstrap 调用链；本次测试进程没有 7709 连接，不能把该体映射到本次 7100/6100 字段。

## 6. 下载文件与后继连接

6100 的下载对象长 1892 B，由帧 500（offset 138732，1400 B）和帧 501（offset 140220，492 B）组成：

- `field20=1`、`field44=1824`、`field52=9`。
- `penc` 位于 60 和 416。
- UTF-16 配置从偏移 422 开始，共识别 20 行，内容是 5188 服务器列表；本次下载对象未发现账号或密码配置行。
- 网络侧实际选中的行情服务器是 `103.141.11.1:5188`，首次 SYN 为帧 503 / offset 140888。

本次 PID `40504` 未连接 7709，未出现 `0x0547`。因此当前证据只证明“6100 登录后选择 5188”，不能证明某个 7100 字段被传给 7709。

## 7. Rust 应保存的最小状态

1. 用户账号和运行期密码句柄；密码不得序列化。
2. 测速候选和结果：6100/7100 endpoint、RTT、响应状态和选择结果。
3. 正式登录 endpoint、请求/响应角色、字典版本 SHA-256。
4. 下载对象解析出的行情服务器列表、被选中的 `103.141.11.1:5188` 和市场/权限字段。
5. 字典解压后的会话响应对象；未解析字段保留长度和 hash，不保存明文凭据。
6. 独立的 7709 bootstrap 状态。不能从本次 5188 会话假定存在 7709 token。
